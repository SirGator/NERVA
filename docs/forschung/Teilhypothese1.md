# Hypothese 
Ein rekurrentes Spiking-Netzwerk kann allein durch lokale Plastizität und die natürlichen Konsequenzen seiner Handlungen sensorimotorische Regelmäßigkeiten lernen und sein Verhalten verändern, ohne dass ein globales System vorgibt, welche Handlung richtig ist.

1. Das Netzwerk lernt sensorimotorische Regelmäßigkeiten.
2. Das Gelernte verändert später sein Verhalten.
